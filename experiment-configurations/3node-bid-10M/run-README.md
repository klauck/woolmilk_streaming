# Run: 3node-bid-10M

3-node stateless bid benchmark, full matrix, smoke (iterations=1).

## Topology
source `192.168.2.80` -> processing `192.168.2.81` -> sink `192.168.2.82`  (see `topology.png`)

## Fixed
- dataset: nexmark BID, 10M tuples, 5 cols `auction,bidder,price,channel,date_time`
- source generates via `nexmark` at runtime (`stream=nexmark_bid`, `store_input`)
- encoding target column: `channel`
- rate: maxbps (no throttle)

## Varied (240 experiments)
| dim | values |
|---|---|
| batch | 5k, 10k, 25k, 50k, 100k |
| buffering | on, off |
| compression | none, lz4, zstd |
| encoding | none, dictionary(channel) |
| selectivity | all 100%, `channel>'H'` 50%, `channel<'B'` 12.5%, `channel>'z'` 0% |

iterations = 1 (smoke). Set `SETTINGS["iterations"]=3` in `scripts/generate-config.py`
and regenerate for the real run.

## Files
- `benchmark-3node-bid-10M.json` — benchmark config (this is the one to launch)
- `cluster-3node-bid-10M.json` — cluster deploy config (processing+sink)
- `topology.png`
- result logs `<timestamp>_<name>/itr_0/` are copied here after the run

## Launch (from woolmilk repo; cluster `.80/.81/.82` must be reachable)
```
python -m woolmilk.benchmark \
  --config-file experiment-configurations/3node-bid-10M/benchmark-3node-bid-10M.json \
  --experiment-dir experiment-configurations/3node-bid-10M \
  --mode remote
```
Then copy the produced result folders into `thesis-ms/experiment-configurations/3node-bid-10M/`.
Cluster was DOWN at generation time — bring `.80/.81/.82` up first.
